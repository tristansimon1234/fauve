# WhatsApp (détails)

WhatsApp interface principale sur téléphone, réponses refusées par Meta. Les règles de base sont dans CLAUDE.md (« WhatsApp »).

Détail déplacé de CLAUDE.md le 4 novembre 2026, mot pour mot : un paragraphe par fonction. Quand une fonction change, son paragraphe change ici.

- Une réponse que WhatsApp refuse (le 29 octobre, chaque envoi du numéro d'Edith refusé par Meta, erreur 131037 « needs display name approval ») est quand même gardée, marquée (`payload.undelivered` : code, mots de Meta, moment ; `deliveryError` dans `inbound.ts`) : elle se lit dans l'app, l'historique du modèle dit qu'elle ne l'a pas reçue (« redis-lui l'essentiel », `toModelHistory`), et ce qu'elle a lancé (la lecture de son site, un montage) part quand même. Perdue, chacun de ses « Alors ? » refaisait tout le tour (son site lu quatre fois) et la lecture du style de son site, lancée après la réponse, ne partait jamais : la carte Style de l'app l'attendait.
- WhatsApp est l'interface principale sur téléphone (Tristan : « WhatsApp interface principale sur mobile : page quand nécessaire optimisée mobile ») ; l'app elle-même ne s'ouvre pas sur un téléphone (Tristan : « l'app ne devrait pas être accessible sur le téléphone, mis à part les pages mobiles ») : `proxy.ts` envoie un téléphone (indice client `Sec-CH-UA-Mobile`, sinon son user agent ; une tablette garde l'app) qui ouvre une page de l'app (`APP_ONLY`) vers `/sur-whatsapp` (« Sur ton téléphone, je suis sur WhatsApp », « Ouvrir WhatsApp », ses factures, les offres), et la page d'une publication vers sa page téléphone (`/v/{id}`) ; « Gérer mon abonnement » (le portail Stripe, `openPortal('/factures')`) est sur `/factures` ; le menu et la barre d'onglets du téléphone de l'app restent dans le code : ce qui demande un écran passe par une page faite pour le téléphone (groupe `(action)`, sans menu), derrière un bouton sous le message d'Edith (lien de connexion à usage unique, 24 h) : `/v/[id]` (une publication), `/depot` (ses fichiers), `/connect` (ses comptes), `/voix` (la voix de ses Reels : écouter et choisir, quand en mettre une, cloner la sienne ; `chooseVoice` enregistre d'un geste et Edith le redit sur WhatsApp dans la fenêtre de 24 h, sinon le bouton de retour a son message tout prêt), `/abonnement?next=/merci` (les offres, « 1 Reel de plus », l'offre au-dessus ; après Stripe, `/merci` la renvoie sur WhatsApp avec « C’est bon, c’est payé ! On y va » tout prêt, son message relançant Edith). Outil `get_page_link` (voix, abonnement ; purposes `voice`, `billing`) ; jamais un lien écrit ni une liste de voix à choisir à l'aveugle.
