# Connexion

Liens de connexion à usage unique et boutons WhatsApp, appairage sur ordinateur par QR.

Détail déplacé de CLAUDE.md le 4 novembre 2026, mot pour mot : un paragraphe par fonction. Quand une fonction change, son paragraphe change ici.

- Connexion : téléphone + code envoyé sur WhatsApp via le Send SMS hook (`/api/auth/send-sms`). Lien magique et QR ouvrent la session côté serveur via `openSessionForPhone` (le hook capture le code dans `pending_server_logins` au lieu de l'envoyer). Les liens d'une publication (`open_post`) valent 24 h au lieu de 15 min, toujours à usage unique ; ouvrir le lien (GET) ne consomme rien : une petite page envoie un formulaire (POST) par script, et seul ce POST ouvre la session, pour que les robots d'aperçu de lien (WhatsApp, Facebook…) ne l'utilisent pas avant la gérante ; un lien déjà utilisé ou expiré mène directement à la page si la session est encore ouverte. Les liens sont courts (`/l/{jeton}`, 22 caractères, la page visée gardée avec le jeton, `login_tokens.next` ; `/auth/link/…?next=` reste pour les anciens) et, sur WhatsApp, jamais collés en entier : la page passe derrière un bouton sous le message (Tristan : « les liens qu'envoie Edith il faudrait les soigner »), « Voir la vidéo », « Voir mon carrousel », « Envoyer mes fichiers », « Relier mes comptes »… (`sendLinkButton`, message `cta_url` de WhatsApp ; `sendLinkThenReply` quand le message a aussi des boutons de réponse, WhatsApp n'en mettant qu'une sorte par message ; texte avec le lien si WhatsApp refuse). `get_post_link` et `get_connect_link` posent ce bouton (`extras.link`, le lien à usage unique fait à l'envoi) au lieu de donner un lien à Edith.
- Commencer et se connecter sur ordinateur sans SMS ni modèle Meta (`lib/auth/pairing.ts`, table `pairing_requests`) : `/commencer` (ou `?connexion`) montre un QR qui ouvre WhatsApp avec « Bonjour Edith ! Code : XXXXXX » ; ce message exact, et rien d'autre (`PAIRING_TEXT`), reçu (`inbound.ts`, `claimPairing`, avant l'agent) relie le numéro (et crée le studio s'il est nouveau), puis Edith demande sur WhatsApp si ce code est sur son écran, avec « Oui, c’est mon écran » / « Ce n’est pas moi » (`answerPairing`, `pairing_requests.confirmed_at`) : un message écrit pour elle par quelqu'un d'autre (un lien wa.me avec son code) ouvrait sa session sur l'écran de l'autre ; la page attend (`checkPairing`, toutes les 2 s, « Touche « Oui, c’est mon écran » sur WhatsApp… » une fois le message reçu) puis `/auth/pair` ouvre la session (`openSessionForPhone`) pour le seul navigateur qui a le secret (cookie `fauve_pair`). Accueil : sur ordinateur « Commencer » mène à `/commencer`, sur téléphone à WhatsApp. `/connexion` propose aussi le message WhatsApp.
